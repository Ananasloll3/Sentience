- [x] **Perception** : ouïe physique, voix (Simple Voice Chat), vue, odorat, douleur, toucher, communication, mémoire unifiée
- [x] **Règles par mod** : chaque mod règle la physique de la perception pour ses propres agents
- [ ] **Behavior Trees** : séquences, sélecteurs, décorateurs, services, tâches ; en JSON rechargeable avec `/reload`
- [ ] **Navigation v2** : A* asynchrone et hiérarchique, portes, échelles, sauts, réparation dynamique des chemins, évitement entre agents
- [ ] **EQS** : requêtes d'environnement (couverture, hors de vue, contournement, cachettes)
- [ ] **Escouades** : rôles, coordination
- [ ] **Director** : gestion de la tension, idéal pour l'horreur
- [ ] **Overlay de debug client** : cônes de vision, chemins, Blackboard en direct
- [ ] **Plusieurs modèles par type** de mob vanilla (cumul entre mods)
