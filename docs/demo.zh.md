# 演示模组

仓库中包含一个独立的演示模组（`src/testmod`），它永远不会随库一起发布。
它展示了如何使用每项功能，并提供了一张测试竞技场地图。

```bash
./gradlew runTestmodClient
```

![演示生物](assets/mobs.png)

## 生物

| 生物 | 测试内容 |
|---|---|
| **潜伏者（Stalker）** | 失明：只有听觉（+ 麦克风）、触觉、痛觉 |
| **哨兵（Sentinel）** | 失聪且静止：只有视觉。向真正看到的目标射击，敲响所有生物都能听到的警钟，并用无线电通知盟友 |
| **猎犬（Hound）** | 嗅觉：一步步沿着你的踪迹追踪。它的规则：雨不会冲淡踪迹 |
| **憎恶体（Abomination）** | 全部感官 + 一个自定义组件（怕光）+ 一个读取黑板的 goal；开始追猎时会通知其他生物 |
| **僵尸**（原版） | 对玩家和村民的听觉与视觉，通过 `AgentTemplates` 添加 |

演示模组有**自己的规则**：头戴雕刻南瓜可以对它的生物起到伪装作用。
僵尸使用默认规则——南瓜骗不了它们。

## “Sentience - Arènes de test” 地图

可在 [releases](https://github.com/Ananasloll3/Sentience/releases) 中下载。解压到 `run/saves`。
你会在夜晚出生于中心区域，竞技场分布在道路两旁。

| 竞技场 | 内容 |
|---|---|
| **潜伏者** | 4 个房间：沙砾、羊毛（脚步声被消音）、瀑布（掩盖声音）、机械装置和一个羊毛藏身处 |
| **哨兵** | 一半明亮一半黑暗的庭院；掩体、玻璃、铁栏杆；箱子（隐身、火把、南瓜）；狗窝里有一个潜伏者，警报响起时会冲出来 |
| **猎犬** | 蜿蜒的小路、需要打开的围栏、切断踪迹的河流、尽头的小屋 |
| **憎恶体** | 黑暗的房子，每个房间一盏灯和一个拉杆，衣柜，地毯 |

`/sentiencetest arene <rodeur|sentinelle|flaireur|abomination|toutes>` 可以在任意位置重建竞技场。
