# 调试与测试工具

## `/sentience debug`

开启或关闭调试显示（需要管理员权限）：

- **每个智能体头顶**：警觉等级、关注点来自哪种感官（👂 听觉、👁 视觉、👃 嗅觉、
  ⚔ 痛觉、✋ 触觉、📣 无线电）、分数、不确定性（±）、视觉进度条、细节层次；
- 在智能体**认为**听到声音的位置显示**粒子**（颜色表示噪音类型）；
- 你周围的**气味踪迹**：绿色 = 气味，红色 = 血迹，灰色 = 水中；
- 动作栏中显示**你的麦克风音量**（需要 Simple Voice Chat）。

```
HUNT  👂 22.2 ±2.9  👁40%
```

退出调试后，生物的真实名称会恢复；如果调试名称不小心随世界一起保存，重新加载时也会消失。

## `/sentience bruit <dB>`

在你的位置发出一个测试噪音。

## 演示模组工具

| 命令 | 效果 |
|---|---|
| `/sentiencetest marcheur <位置> <秒数> [潜行]` | 一个假玩家来回走动（发出声音并留下气味） |
| `/sentiencetest piste <起点> <终点>` | 铺设一条气味踪迹，就像有人刚从 A 走到 B |
| `/sentiencetest arene <名称>` | 在你面前建造或重置一个测试竞技场 |

!!! note "假玩家的限制"
    假玩家并不真正存在于世界中：它会发出声音、留下气味，但**视觉**看不到它。
    请用你自己或村民来测试视觉。
