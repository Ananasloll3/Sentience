# 性能

Sentience 设计为每个世界可容纳数十个智能体。

| 机制 | 效果 |
|---|---|
| **细节层次** | 远离玩家的智能体思考频率降低 2 到 20 倍，但不会失去反应能力 |
| **批量处理噪音** | 噪音每 tick 统一分发一次；重复的噪音（同一来源、同一类型）会被合并；每 tick 最多 256 个 |
| **两步听觉** | 只有当噪音在无障碍时可被听到，才会计算方块穿透（遮挡） |
| **背景噪音缓存** | 每个聆听者每秒重新计算一次，并在聆听者之间错开 |
| **间隔视觉检测** | 每个智能体每 3 到 4 tick 检测一次 |
| **按区块存储踪迹** | 查找气味时只扫描鼻子周围的区块 |
| **没有智能体就没有开销** | 如果某个世界中没有智能体在听，噪音会被立即丢弃 |

## 建议

- 保持合理的范围（`withMaxRange`、`withRange`）：它们决定了工作量的上限。
- 纯装饰用的智能体不需要 `defaultGoals`。
- 在你的组件中，使用 `deltaTicks` 和倒计时，而不是每个 tick 都执行所有逻辑。
