# 路线图

- [x] **核心**：智能体、黑板、组件、细节层次、调试
- [x] **感知**：物理听觉、语音（Simple Voice Chat）、视觉、嗅觉、痛觉、触觉、通信、统一记忆
- [x] **按模组区分的规则**：每个模组为自己的智能体调整感知物理
- [x] **行为树**（0.2.0）：序列、选择器、装饰器、服务、任务；使用 JSON，可通过 `/reload` 重新加载
- [x] **EQS**（0.2.0）：环境查询（掩体、视线外、包抄、逃跑）
- [x] **每种生物类型支持多个模板**（0.2.0）：在模组之间合并
- [ ] **导航 v2**：异步分层 A*、门、梯子、跳跃、动态路径修复、智能体之间的避让
- [ ] **小队**：角色、协同
- [ ] **导演系统**：紧张感管理，非常适合恐怖题材
- [ ] **客户端调试叠加层**：视野锥、路径、实时黑板

有想法？请提交 [issue](https://github.com/Ananasloll3/Sentience/issues)。
