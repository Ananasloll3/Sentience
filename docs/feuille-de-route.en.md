# Roadmap

- [x] **Core**: agent, Blackboard, components, level of detail, debug
- [x] **Perception**: physical hearing, voice (Simple Voice Chat), sight, smell, pain, touch, communication, unified memory
- [x] **Per-mod rules**: each mod tunes the physics of perception for its own agents
- [ ] **Behavior Trees**: sequences, selectors, decorators, services, tasks; in JSON, reloadable with `/reload`
- [ ] **Navigation v2**: asynchronous hierarchical A*, doors, ladders, jumps, dynamic path repair, avoidance between agents
- [ ] **EQS**: environment queries (cover, out of sight, flanking, hiding spots)
- [ ] **Squads**: roles, coordination
- [ ] **Director**: tension management, ideal for horror
- [ ] **Client debug overlay**: vision cones, paths, live Blackboard
- [ ] **Multiple templates per vanilla mob type** (combined across mods)

Ideas? Open an [issue](https://github.com/Ananasloll3/Sentience/issues).
