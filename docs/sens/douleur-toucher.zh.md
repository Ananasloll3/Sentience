# 痛觉与触觉

## 痛觉

```java
.damage()
```

智能体受伤时，会知道攻击来自哪里：

- **近战**：攻击者的位置几乎精确（分数 40，`kind = "melee"`）；
- **远程射击**：攻击者的位置，不确定性随距离增大（`"ranged"`）；
- **无射手的弹射物**：智能体会沿弹道反推来源。

使用默认阈值时，一次攻击会直接触发追猎。

## 触觉

```java
.touch()                                   // 玩家
.touch(e -> e instanceof PlayerEntity || e instanceof VillagerEntity)
```

碰到智能体的目标会暴露自己（精确位置，分数 25），即使在完全黑暗中，即使智能体又瞎又聋。
